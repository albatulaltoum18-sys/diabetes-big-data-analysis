Diabetes Big Data Analysis using Apache Spark

Project Overview
This project presents a big data analysis workflow applied to a diabetes dataset using Apache Spark.
The analysis focuses on medical and demographic attributes such as glucose level, BMI, age, insulin,
and blood pressure to explore patterns related to diabetes outcomes.

Objective
The objective of this project is to demonstrate how Apache Spark can be used for large-scale data
ingestion, cleaning, transformation, and analysis in a healthcare context.

Dataset
The dataset contains medical diagnostic measurements commonly used for diabetes risk assessment.
It includes features such as glucose, blood pressure, BMI, age, insulin, and outcome labels.

Methodology
The analysis follows four main stages:
Data ingestion using Spark DataFrames
Data cleaning by handling missing and invalid values
Feature transformation including age grouping and glucose level categorization
Data analysis using Spark aggregation and group operations

Key Results
The analysis shows clear differences between diabetic and non-diabetic patients in glucose levels,
BMI, and age distribution.
Older age groups and higher glucose levels are associated with higher diabetes risk.
